# Влад Фролов — портфолио

Сайт: https://frlvv.github.io/portfolio/

React + TypeScript + Vite. Дизайн перенесён из Figma, начиная с узла `38:419` в файле `1hVDN7d9qO94lTE5FRy1T1`.

## Разработка

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Проверка готовой сборки: `npm run preview`.

## Публикация

В Settings → Pages выбрать Source: GitHub Actions. Каждый push в `main` собирает и публикует `dist` через `.github/workflows/deploy.yml`.

## Содержимое

- `src/App.tsx`: главная, Contact, кейс и слайдер.
- `src/styles.css`: стили, адаптации и анимации.
- `public/assets`: оригинальные изображения и SVG из Figma; не зависят от временных ссылок Figma.
- `public/Vlad-Frolov-CV.pdf`: исходное CV с заменённой ссылкой на портфолио. Внешний вид сохранён.

Contact копирует `v@frlvv.ru` и открывает Telegram `vf433`. Кейс открывается модалкой, закрывается крестиком, кликом снаружи или Escape. Прокрутка страницы сохраняется. В слайдере — стрелки, индикаторы, свайп и клавиатура. Скриншоты не открываются в отдельной галерее.

Широкий экран: колонки 300 / 640 px с промежутком 80 px. Планшет: гибкие колонки. До 700 px: одна колонка. Поддерживаются `prefers-reduced-motion`, клавиатура и сенсорные экраны. Шрифт Golos Text поставляется локально.

Вторая карточка оставлена заглушкой по макету. Раздел «Гипотезы и решения» пока повторяет «Исследование», как в исходной Figma; эти части можно заменить готовым содержимым позднее.
